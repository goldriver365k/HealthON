## 1. 한 일 요약
1. **가족 초대·연결 서버 함수** (🔒): 초대 코드 만들기 / 코드 입력 / 공유 항목 바꾸기 / 그만두기 / 공유 정보 보기
2. **가족은 건강정보 표를 직접 읽지 못함**: 오직 `get_shared_summary` 서버 함수로만 받고, 함수가 **볼 때마다** 연결 상태·공유 항목·정보 주인의 건강정보 동의를 다시 검사하고 **열람 기록**을 남김
3. **공유 범위 최소화**: 최근 7일 수치, 오늘 약 확인 여부(**약 이름 없이** 시간대만), 다음 병원 일정만. 메모·진료 질문은 어떤 경우에도 공유 안 함
4. **실명 대신 호칭**: 가족에게는 정보 주인이 정한 호칭(예: 어머니)만, 주인에게는 주인이 부르는 호칭(예: 딸)만 보임. 이메일 등은 서로 보이지 않음
5. **초대 코드 보안**: 암호학적 난수 6자리, 서버에는 해시만 저장, 24시간 만료, 1회용, 틀리면 1시간에 5번까지
6. **정보 주인이 확인 가능**: 가족 상세 화면에 "최근 7일 동안 N번 봤어요 · 마지막 본 때"
7. **건강 통계**: 건강기록 탭에 **‘약’** 추가 — 최근 7·30일 "먹었다고 표시한 횟수", 날짜별 막대(0부터 시작해 길이가 값에 비례), 약별 현황. **비율·점수·평가 없음**
8. **체험 모드**: 초대 코드는 `123456`, 입력하면 '체험 가족'이 예시로 연결됨

## 6. 알아 둘 점
1. **가족 정보는 화면을 열 때만 불러옵니다.** 앱을 켤 때마다 불러오면 가족이 보지도 않았는데 '봤어요' 기록이 쌓이기 때문입니다.
2. 가족이 보는 "오늘 약"은 **정보 주인의 한국 날짜** 기준입니다 (해외 거주 가족은 날짜가 다를 수 있음).
3. 가족 권한은 **보기만**입니다 (계획대로). 대신 기록 입력은 2차 이후 기능입니다.
4. 체험 모드의 '체험 가족'은 앱을 다시 켜면 사라집니다.
